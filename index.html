Política de Privacidad — Mail Merge para Sheets + Gmail

Extensión de Chrome

Última actualización: 21 de noviembre de 2026.

Qué es Mail Merge para Sheets + Gmail

Es una extensión de Chrome que combina filas de una Google Sheet con plantillas de correo/Chat guardadas por el propio usuario, y envía un mensaje personalizado por cada fila usando la propia cuenta de Google del usuario (Gmail y/o Google Chat).

Datos que se guardan solo en tu navegador

  • Plantillas de correo/Chat (asunto + cuerpo con variables {{columna}}) que el propio usuario escribe y guarda.
  • Configuración de envío: ID de la Sheet conectada, columnas elegidas, cuentas de Google agregadas, bloques de envío programado.
  • El/los link(s) de CRM que el usuario agrega manualmente en "Agregar otro sitio de CRM" (opcional).

Todos estos datos se guardan únicamente en el almacenamiento local de tu propio navegador (chrome.storage, provisto por Chrome para extensiones) — nunca llegan a ningún servidor nuestro. Esta extensión no tiene backend propio.

Datos que se envían a Google (con tu propia cuenta)

La extensión usa las APIs oficiales de Google, autenticándose con tu propia cuenta vía OAuth (chrome.identity):

DatoA dóndePara qué
Las filas de tu Google Sheet (nombres, correos, teléfonos u otras columnas que vos elijas) Google Sheets API Leer los datos para combinarlos con tu plantilla, y escribir de vuelta una columna de confirmación de envío
El asunto/cuerpo de cada correo ya combinado con los datos de la fila Gmail API Enviar el correo desde tu propia cuenta de Gmail
El mensaje ya combinado (si activás esa opción) Google Chat API Enviar el mensaje desde tu propia cuenta de Google Chat
Tu email (identidad) Google (userinfo.email) Mostrar qué cuenta está conectada en el popup

Todo este tráfico va directo entre tu navegador y los servidores de Google, usando tu propia sesión — nosotros (los autores de la extensión) no vemos, no recibimos ni guardamos ninguno de estos datos en ningún servidor propio.

Integración opcional con tu CRM

Si vos mismo agregás la URL de tu CRM en "Agregar otro sitio de CRM", la extensión puede leer los datos del caso que tengas abierto en esa pestaña (solo cuando vos hacés clic en "Enviar caso abierto a la Sheet") para agregarlos como una fila nueva en tu Sheet. Esto nunca se activa automáticamente ni en sitios que vos no hayas agregado a mano.

La extensión no usa ninguno de estos datos para publicidad, no los vende, y no los usa para ningún fin distinto de los descritos acá.

Control sobre tus datos

Podés en cualquier momento, desde el propio popup de la extensión:

  • Editar o eliminar tus plantillas.
  • Desconectar una cuenta de Google.
  • Quitar un sitio de CRM agregado.

Desinstalar la extensión elimina todos los datos guardados localmente en tu navegador (plantillas, configuración, cuentas conectadas). Revocar el acceso desde tu cuenta de Google (myaccount.google.com/permissions) elimina el permiso de la extensión para usar la API en tu nombre.

Retención

Datos locales (plantillas, configuración): sin plazo automático, se conservan hasta que vos los eliminás manualmente o desinstalás la extensión. No hay ningún dato retenido en un servidor nuestro, porque no existe tal servidor.

Permisos que usa la extensión

La extensión solicita únicamente los permisos necesarios para su función: identity (autenticarte con tu cuenta de Google), storage (guardar localmente tus plantillas y configuración), tabs/tabGroups (organizar pestañas), scripting y acceso opcional a sitios que vos agregás manualmente (tu CRM), y alarms (envíos programados). Acceso a sheets.googleapis.com, www.googleapis.com (Gmail) y chat.googleapis.com para las funciones ya descritas. El detalle técnico de cada permiso está disponible públicamente en el código fuente de la extensión.

Cambios a esta política

Si el funcionamiento de la extensión cambia de forma que afecte el tratamiento de datos descrito acá, esta política se actualizará y se indicará la nueva fecha arriba.
